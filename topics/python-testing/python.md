# Какие модули в Python есть для тестирования? Какие отличия, плюсы и минусы?

## Коротко

Стандартный `unittest` и де-факто народный `pytest`; плюс слой моков. 

## Развёрнуто

unittest всегда «в коробке», но многословен. Pytest — меньше кода, фикстуры, плагины, удобные assert. Минус pytest — внешняя зависимость. Для Django: TestCase или pytest-django. Выбор команды важнее религии.
