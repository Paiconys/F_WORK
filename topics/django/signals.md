# signals (хотя бы «что это»)

## Коротко

Сигналы — колбэки на события фреймворка/моделей (например `post_save`).

## Развёрнуто

Позволяют реагировать без правки всех мест создания объекта. Риск — неявный поток «магии». Мы для WS сознательно шлём событие из `create()`, а не из signal — проще трассировать.
