# Docker

## Коротко

Контейнеризация: упаковать приложение и окружение, чтобы одинаково запускать везде.

## Развёрнуто

Image — неизменяемый шаблон; container — запущенный процесс; volume — данные вне жизненного цикла контейнера. Зачем: меньше «у меня работает», изолированные зависимости, проще CI/CD. Не путать с ВМ: контейнеры делят ядро хоста.
