# Reverse proxy (nginx)

## Коротко

Входной HTTP-сервер перед приложением: TLS, статика, проксирование на backend.

## Развёрнуто

Клиент бьёт в nginx; дальше `/api` → app, статика с диска, иногда `/ws` → ASGI. Зачем: один origin, сжатие, буферизация, безопасность, разгрузка app-сервера от статики. Альтернативы: Caddy, Traefik, cloud LB.
