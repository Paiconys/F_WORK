# image vs container vs volume

## Коротко

Image — неизменяемый шаблон; container — запущенный процесс из image; volume — постоянное хранилище вне жизненного цикла контейнера.

## Развёрнуто

Пересборка контейнера не должна убивать данные БД и загруженные media — поэтому volumes. Image версионируют/пушат в registry.
