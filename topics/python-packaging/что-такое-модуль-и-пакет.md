# Модуль и пакет

## Коротко

Модуль — файл `.py`. Пакет — набор модулей в директории (пространство имён).

## Развёрнуто

Импорты строят структуру проекта (`package.module`). Пакет обычно с `__init__.py` (namespace packages — отдельная тема). Без пакетов проект быстро превращается в кашу файлов. На собесе: чем модуль отличается от пакета и зачем `__init__.py`.
