# Что такое виртуальное окружение? Зачем оно нужно? Какие инструменты для этого используются?

## Коротко

Изолированный набор пакетов проекта, чтобы зависимости разных проектов не конфликтовали. 

## Развёрнуто

Инструменты: `venv` (стандарт), `virtualenv`, Poetry, Pipenv, conda. Типичный поток: создать → активировать → `pip install -r requirements.txt`. В git не кладут. Docker образ — другая изоляция; локальный venv всё равно удобен для IDE.
