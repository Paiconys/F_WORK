# Абсолютные vs относительные импорты

## Коротко

Абсолютный — путь от корня пакета. Относительный — относительно текущего модуля (`.` / `..`).

## Развёрнуто

`from myapp.models import X` vs `from .models import X`. Абсолютные проще читать в большом проекте; относительные удобны внутри пакета. Скрипт, запущенный «как файл», часто ломает относительные импорты — нужна пакетная структура/`-m`.
