# Exceptions: как обрабатывать, зачем свои исключения

## Коротко

Ошибки сигнализируют через исключения; свои типы нужны, чтобы ловить доменные случаи отдельно от прочих сбоев. 

## Развёрнуто

`try/except/else/finally`. Ловите конкретные типы, не всё подряд. На границе API превращаете в понятный HTTP-ответ. Свои классы (`ValidationDomainError`) делают обработку выразительной.
