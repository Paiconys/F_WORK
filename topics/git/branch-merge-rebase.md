# branch / merge / rebase

## Коротко

Ветка — линия работы; merge — слить истории; rebase — перенести коммиты на новый базовый tip. 

## Развёрнуто

Feature-branch → PR → merge в main — рабочий поток. Rebase делает историю линейнее, но переписывает коммиты: на общих ветках опасно. Для джуна достаточно уверенно вести ветку задачи и мержить через review.
