### .gitignore / не коммитить секреты

#### Коротко
Игнор исключает мусор и секреты из репозитория; пароли/ключи только в env.

#### Развёрнуто
Типично: `.env`, `venv`, `__pycache__`, локальные media. Утечка SECRET_KEY = ротация. В репо кладут `.env.example` без значений.

### branch / merge / rebase

#### Коротко
Ветка — линия работы; merge — слить истории; rebase — перенести коммиты на новый базовый tip. 

#### Развёрнуто
Feature-branch → PR → merge в main — рабочий поток. Rebase делает историю линейнее, но переписывает коммиты: на общих ветках опасно. Для джуна достаточно уверенно вести ветку задачи и мержить через review.

### conflict

#### Коротко
Git не смог сам совместить правки одного участка — нужно вручную собрать итог. 

#### Развёрнуто
Маркеры конфликта, выбор логики, `add`, завершение merge/rebase, прогон тестов. Профилактика: маленькие диффы и частый sync.

---

### Git

#### Коротко
Система контроля версий: история изменений, ветки, совместная работа. 

#### Развёрнуто
Коммит = снимок + сообщение. Remote (GitHub), PR/review. Базовые команды: status/add/commit/pull/push/branch/checkout/merge.
