# Какие бывают типы данных в Python

## Коротко

Встроенные типы делят на числа, последовательности, множества, словари, bool/None, байты — и всё это объекты; плюс типы ваших классов. 

## Развёрнуто

- **Числа:** `int`, `float`, `complex`
- **Текст:** `str` 
- **Последовательности:** `list`, `tuple`, `range` 
- **Множества:** `set`, `frozenset` 
- **Отображения:** `dict` 
- **Логика/пусто:** `bool`, `NoneType` 
- **Бинарные:** `bytes`, `bytearray`, `memoryview` 
Отдельно удобно смотреть через призму **изменяемости** (следующий вопрос), но «какие бывают» на собесе ждут именно эти группы + понимание, что пользовательский класс — тоже тип.
