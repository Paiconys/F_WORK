# Какие типы данных относятся к изменяемым, какие нет

## Коротко

Изменяемые — `list`, `dict`, `set`, `bytearray`. Неизменяемые — `int`, `float`, `str`, `tuple`, `frozenset`, `bool`, `None`, `bytes`. 

## Развёрнуто

Mutable меняются «на месте» (`append`, запись по ключу). Immutable при изменении дают новый объект (`s + "!"`). Отсюда следствия: ключи `dict`/`элементы set` должны быть hashable (обычно immutable); дефолт `def f(a=[])` опасен; передача list в функцию позволяет менять его снаружи, а «переназначение» `x = 1` внутри функции — нет.

## Пример

Код: [`mutability_demo.py`](./examples/mutability_demo.py)

```python
"""

Dependencies: none (stdlib)
Mutable vs immutable и передача в функцию."""

def rebind(x):
 x = [99] # локальная перепривязка — снаружи не видно
 return x

def mutate(x):
 x.append(99) # мутация объекта — видно снаружи

a = [1]
rebind(a)
print(a) # [1]

mutate(a)
print(a) # [1, 99]
```
