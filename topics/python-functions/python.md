# Как в Python передаются аргументы в функцию (изменяемые и неизменяемые)

## Коротко

В функцию передаётся ссылка на объект; перепривязка имени локальна, мутация объекта видна снаружи. 

## Развёрнуто

Это не «по значению» и не совсем «по ссылке как в C++». Вызов даёт тот же объект. `lst.append(1)` изменит исходный list. `lst = []` внутри функции только локально отвяжет имя. Поэтому контракт функции с mutable нужно документировать: «изменит переданный dict» или копировать вход.

## Пример

Код: [`mutability_demo.py`](./examples/mutability_demo.py)

```python
"""

Dependencies: none (stdlib)
Mutable vs immutable и передача в функцию."""

def rebind(x):
 x = [99] # локальная перепривязка — снаружи не видно
 return x

def mutate(x):
 x.append(99) # мутация объекта — видно снаружи

a = [1]
rebind(a)
print(a) # [1]

mutate(a)
print(a) # [1, 99]
```
