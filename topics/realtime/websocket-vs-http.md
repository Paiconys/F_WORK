# WebSocket vs HTTP

## Коротко

**HTTP** — Hypertext Transfer Protocol (протокол передачи гипертекста) — короткий запрос/ответ; WebSocket — долгоживущий двусторонний канал. 

## Развёрнуто

HTTP идеален для CRUD. WS — когда сервер сам пушит «появился комментарий». Мы не заменяем REST сокетом: REST пишет, WS сигналит обновить.
