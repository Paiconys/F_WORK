# Mutable default argument — что напечатает

## Коротко

Дефолт `x=[]` один на функцию; общий список мутируется между вызовами без аргумента.

## Развёрнуто

Классика собеса. Первый `func()` пишет в общий список. Свой список-аргумент дефолт не трогает. Следующий голый `func()` снова видит накопленное.

## Пример

Код: [`mutable_default.py`](./examples/mutable_default.py)

```python
"""

Dependencies: none (stdlib)
DRILL: mutable default argument — что напечатается?

Запусти файл и сравни с прогнозом вслух.
"""

def func(x=[]):
 # ВАЖНО: список-дефолт создаётся ОДИН раз при определении функции
 x.append(1)
 print(x)

func() # [1] — использовали общий дефолт
func([1, 2]) # [1, 2, 1] — свой список, дефолт не трогали
func() # [1, 1] — снова общий дефолт (там уже был 1)
func([2, 3]) # [2, 3, 1] — снова свой список

# Безопасный паттерн:
def func_safe(x=None):
 if x is None:
 x = []
 x.append(1)
 print(x)
```
