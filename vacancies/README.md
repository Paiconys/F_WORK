## Workflow (как добавлять вакансию)

1. Кидаешь **ссылку** на вакансию.
2. Выписываешь **must / nice** требования.
3. Для каждого требования:
   - блок уже есть в [`questions.md`](../questions.md) → ставишь его в таблицу «Учить по блокам»;
   - блока нет (новая технология) →
     1. добавляешь имя в список блоков в `questions.md`,
     2. создаёшь `topics/<блок>/<блок>.md` (вопросы + коротко/развёрнуто + пример при необходимости),
     3. дописываешь вопросы в секцию блока в `questions.md`,
     4. только потом ссылаешь блок из файла вакансии.
4. Создаёшь `vacancies/NN-slug.md`: ссылка, требования, таблица блоков, оставшийся **Gap** (то, что ещё не оформили блоком).
5. Строка в таблице выше.

**Идея:** `topics/` — общая шпаргалка на все собесы; `vacancies/` — «что учить под эту вакансию».

## Как готовиться по вакансии

1. Открой файл вакансии.
2. Иди по таблице **Учить по блокам** (must → should → nice).
3. Gap — либо новый блок в `topics/`, либо внешний материал, пока не завели блок.
