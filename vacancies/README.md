## Как пользоваться

1. Открой вакансию.
2. Смотри таблицу **Учить по блокам**.
3. Проходи `topics/<блок>/<блок>.md` (+ вопросы из `questions.md`).
4. Строки **Gap** — тем ещё нет в репо; либо добавь блок, либо учи отдельно.

Новую вакансию: `05-...md` + строка в таблице выше.
